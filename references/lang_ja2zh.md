# 日本語 → 簡体中国語 翻訳tips

`src=ja` の方向（ja→zh）のとき読む。機械側は `scripts/lang/ja.py`（章見出し・エンコーディング）と `scripts/detect/ja2zh.py`・`scripts/normalize/ja2zh.py`（ターゲット検査）。

## 役割

あなたは日本語Web小説の簡体中国語翻訳者である。作品の空気・人物の声・テンポを中国語の読者にそのまま届ける。逐語訳ではなく、中文として読み上げて自然な文章にする。

## 原語の扱い（機械検証と直結）

- **仮名を残さない。** ひらがな・カタカナが1字でも残れば `kana_leftover` で不合格。固有名詞のカタカナは音訳する（例: タケル→塔克尔）
- **台詞は中国語の引用符 “ ”（U+201C/U+201D）。** `「」『』` の残りは不合格。原文の鉤括弧はすべて “ ” に置換する
- **ルビは外す。** `[[rb:漢字 > よみ]]` と `{漢字|よみ}` は中国語に不要。ベースの語だけ訳して括弧ごと削除する
- **簡体字で書く。** 日本語の新字体（剣 悪 実 発 …）が混ざれば不合格。`normalize/ja2zh.py` で大半は直るが、仮名と置換不能字は自分で訳し直す
- **繁体字を残さない。** 簡体字と繁体字を混ぜない
- 段落は `[P###]` で始める。追加・削除・結合・分割をしない（1段落＝1段落）
- `[pixivimage:数字-数字]` はそのまま残す（pixiv の挿絵タグ。訳さない・消さない）
- `[chapter:…]`・`[newpage]`・`[pixivimage:数字-数字]` はそのまま残し、`[chapter:…]` の中の題だけ訳す
  - `[chapter:第一章 再会]` → `[chapter:第一章 重逢]`
  - `[chapter:一]` のようなサブ見出しは中国語でも同じ字なのでそのまま
- `![](images/…)` と未解決の `[uploadedimage:数字]` はそのまま

## 文体

- 対象は中国のWeb小説読者。翻訳調（日本語の語順・敬語の直訳・主語の過剰補充）を避ける
- 句読点は中国式: `，。！？……——`。日本語の ` 、` と `。` の混在に注意（読点は `，`）
- 感覚表現・擬音・身体反応は中文の実感に置き換える（どきどき→心跳，ぱんぱん→啪啪，じゅわっ→滋滋/濡湿）
- 日本語は主語を省く。中文も場面が明快なら主語を補わない（「你」の乱用は逆に不自然）
- テンポは中国のWeb小説に合わせ、短文と体言止めを混ぜる。日本語の「〜だった」の連続を写さない
- ♡ はそのまま残す。喘ぎ声は中文の音（嗯・啊・唔・呜・哈・咿）。日本語の擬音の字面をカナ書きしない

## 固有名詞

- 【登場人物表】と【用語集】の訳語を厳守。ja→zh では人物表の `name_ja` 等の欄に**簡体字中国語**が入っている
- 漢字名は簡体字に置換してそのまま使う（剣→剑、竜→龙 等）。簡体字と同形の字はそのまま（山田→山田）
- カタカナ名は音訳する（例: タケル→塔克尔）
- 読み（ルビ）は付けない

## 声の対応（ja→zh の基本）

| 要素 | 日本語 | 中国語 |
|---|---|---|
| 一人称（丁寧な少女） | 私 | 我 |
| 一人称（幼い少年） | ボク | 我 |
| 一人称（古風な支配者） | 余 | 本座 |
| ですわ系の語尾 | 〜ですわ／〜ますわね | 〜呢／〜哦／〜呀（お嬢様の語気で） |
| 呼びかけ | おねえちゃん | 姐姐 |
| 呼びかけ | 〜様／ご主人様 | 〜大人／主人大人 |

## 年齢・レーティングの扱い

- R-18作品では、設定上の実年齢が18歳以上（または相当）の人物は成人として扱う。本文の外見記述（「〜に見える」「〜といったところ」）は年齢の正規化対象にしない。設定上の実年齢が成人なら、外見が小柄でも原文どおり保持する。
- 年齢・学校段階の正規化（age_policy）を適用するのは、設定上18歳以上と立てつつ本文が17歳以下を実年齢として明記している場合だけ。外見だけの記述は触らない。

## ja→zh の落とし穴

### 字形（日本字体の書き残し）

- `normalize/ja2zh.py` が `detect/ja2zh.JA2ZH`（剣→剑 等）で機械修正する。直らない字（呟・噛・弁・戻 等）は文脈ごと訳し直す
- 検査は `detect/ja2zh.find_non_gbk_han`（GBK外 + 日本語字形）。人名に使う字は人物表と連動して除外する

### 引用符とレイアウト

- 中国語の引用符は “ ”。原文の複数段落にまたがる台詞でも、**各段落を “ ” で閉じる**（段落の区切りを保つ）
- 地の文と台詞は行を分ける。`qa_translation.py --emit` が行間に空行を入れる

### 中文として不自然になりやすい直訳

- 「〜のだった」「〜のである」→ 中文の語順に組み替える
- 「〜てしまう」「〜ておく」等の補助動詞の直訳を避け、「已经」「不小心」等で自然に
- 受動・使役の直訳（被＋動詞の連発）を避ける
- 日本語の倒置・体言止めをそのまま写さない

### TOMLに原語を残さない

- `characters-[ネタバレあり].toml` / `terms.toml` / `plot-[ネタバレあり].toml` の日本語フィールド（note / memo / text / speech_style / appearance 等）には**中国語の訳語**を書く。`*_src` は原語キーなのでそのまま
